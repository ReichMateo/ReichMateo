### 📌 Proyecto destacado

**[Gestor Estratégico de Tareas — MateCode](https://github.com/ReichMateo/PIM4)**  
Proyecto Integrador Final de Henry. SPA de gestión de tareas corporativas.

- 🔐 Autenticación con email/contraseña y Google Sign-In, con rutas privadas
- ☁️ Sincronización en tiempo real con Cloud Firestore, aislada por usuario
- ✅ CRUD de tareas con prioridades, vencimientos, drag & drop, búsqueda y filtros
- 📧 Resúmenes por email con AWS SES en una función Serverless de Vercel
- 🧪 Pruebas automatizadas con Vitest y React Testing Library
